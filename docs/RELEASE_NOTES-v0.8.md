# mikubot 0.8.0 · 更容易开始聊天与办事

本版把独立聊天与机器人管理分开，采用初音青绿色界面，并提供软件内使用指南。先连接一个模型即可聊天，QQ、人格蒸馏与电脑能力按需要开启；新建本地会话自动生成 ID。

- **管理员权限**：主人账号改为多个管理员，内置已认证的本地 `mikubot` 账户；QQ 管理员按真实平台账号判断，支持短时配对码及本地确认。允许聊天列表与管理员列表分离，旧版主人账号迁移后不继续作为独立授权来源。
- **本机 QQ 配对**：通过 NapCat/SnowLuma WebUI 鉴权添加 mikubot 专属反向连接，保留其他连接，支持账号选择和受版本核对保护的撤销。QQ 登录、初始化和管理口令仍由用户提供，未知配置版本使用手动连接。
- **电脑任务**：本机 Shell、Python 和文件工具，后台执行、具体动作审批、批准后继续、停止和结果记录。仅管理员可发起，默认关闭；使用当前系统账户权限，工作目录不是隔离沙箱。重启与恢复不会自动重跑命令。
- **双模式人格蒸馏**：角色搜索后确认资料，生成研究、Skill 包与人格；ZIP/文件语料先识别目标说话者，再仅生成人设描写，支持真实人物语料。草稿可预览、试聊、另存，现有人格不自动覆盖。
- **模型与附件**：读取模型列表使用当前表单，费用未知明确显示；附件区分本次参考、长期资料和蒸馏用途。
- **源码交付**：提供白名单源码 ZIP、Python 包配置与 Windows 一条命令准备环境和启动脚本。无需 Node 或前端构建；Linux 无头脚本仍为实验路径。

本版继续保留安装 EXE、便携 ZIP、Planner、分段、会话记忆隔离、群语言、人格知识、MCP 审批和备份功能。原始蒸馏材料、附件、生成包与电脑工作目录文件需另行备份；恢复的操作记录只供查看，不能重新批准或执行。

模型服务和 NapCat/SnowLuma 客户端不包含在发行包中。真实 QQ 收发、连接器不同版本和收费模型的实际效果需使用用户自己的配置验收；测试证据及范围见[测试报告](TEST_REPORT.md)。
