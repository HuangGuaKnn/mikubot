# mikubot 0.9 测试报告

日期：2026-10-18（Asia/Hong_Kong）。Windows x64 / Python 3.12.14 / Node 24.18.0 / PyInstaller 6.22.3 / pywebview 6.2.1。

## 本版验证目标

本版加入原生 Windows 桌面窗口、首次设置管理密码、独立数据目录、供应商与模型目录、运行日志，并修复 QQ 私聊权限迁移。开启电脑控制后，管理员任务默认连续执行；仍可停止或选择逐动作确认。桌面窗口与浏览器使用同一认证流程，启动初始化凭据只证明本机设置权限，不直接登录。默认仅监听回环地址，开启远程须已设置密码；本机免密必须显式选择，不能用于远程登录。

密码模块在真实 Windows DPAPI 环境验证：加盐 scrypt 校验信息由当前 Windows 账户 DPAPI 加密，不保存明文密码；原子写入、损坏文件拒绝登录、并发初始化、随机盐、输入边界、每来源和全局登录限流、12 小时会话、进程重启失效均有测试。

HTTP 集成覆盖首次本机证明不等于登录、远程抢设拒绝、已登录请求、退出、改密、密码文件删除后的旧会话撤销、文件重建及重新设密、聊天记忆保留、备份排除密码、本机免密限制、关闭远程立即撤权、设置不合法时不变更。旧 Cookie 和远程使用内部启动 Token 不能绕过密码；内部 Bearer 仅供真正本机的命令行管理。请求同时验证连接来源和 Host，不信任客户端转发头，IPv4 映射的 IPv6 回环正常识别。HTTPS 反向代理须明确配置域名和 public_url 并保留 Host；代理请求不获得本机初始化权限，认证 Cookie 标记 Secure。

真实浏览器检查首次设密提示、本机初始化证明清除 URL、错误密码、正确登录、退出、改密后旧页面退回登录、网络设置与忘记密码说明。另通过独立测试 API 完成改密和删除密码文件后重新设密，消息及记忆逐项一致。未在用户账户中设置任何实际密码。截图已查看：[登录](docs/login-v0.9.jpg)、[首次设置](docs/setup-v0.9.jpg)。

## 桌面与数据

原生桌面采用 pywebview 的 Windows EdgeChromium 渲染器，禁用外部 JS API，程序内部界面只允许本机来源；程序跳转到其他来源被阻止，用户点击的普通网页链接由系统浏览器打开。实际 Windows 用户环境已渲染本机页面并验证导航限制与关闭。受限执行环境无法初始化 WebView2 的首轮尝试未作为通过，正常审批后使用普通 Windows 用户环境验收成功。

最终打包 EXE 已实际出现独立可见窗口，server.json 标记 desktop；无托盘和带托盘两种脚本验收均通过：二次启动唤醒相同窗口和后台，无托盘关窗停止；有托盘关窗隐藏且后台继续，重新启动恢复原窗口，停止后清理运行记录。另用 computer-use 实际查看源码原生窗口，首次设密页正常渲染；最终 EXE 的进一步页面视觉检查被用户 Esc 中止，未继续操作，也未将 GPU 截图失败的空白图作为通过证据。

默认数据位置为 %LOCALAPPDATA%\mikubot\data，与程序目录分开。显式 --data-dir 保留；旧版安装/源码旁 data 在目标为空且旧实例退出后复制迁移，原目录保留，不覆盖已有目标，不重复使用旧 PID/端口。目录包含链接、旧实例运行、目标非空和迁移失败均有回归。安装器同时检查旧 data 与独立默认数据的实例锁，避免程序运行中替换文件。

## 实际验证边界

没有使用真实 QQ、用户模型密钥或收费模型。已有机器人功能继续采用本地协议替身和脚本模型验收，不把合成测试当作真实模型效果证明。Windows x64 是桌面验收平台；缺少微软 WebView2 Runtime 的设备需要安装运行时，或显式选择 --browser。Linux 为实验性无头源码路径，未做真实系统验收。

HTTP 不加密网络传输。远程入口默认关闭；跨不可信网络需自行配置 HTTPS 反向代理或加密隧道。没有自动修改防火墙或开放公网。删除密码文件要求完全退出后在本机重新设置，应用不会向远程未登录用户暴露本机文件路径。

应用备份不包含密码文件、原始语料、附件、Skill ZIP、文件修改前副本与电脑工作目录，请分别保留。移除程序目录不移除独立默认数据；本版未新增自动删除个人数据的卸载操作。
