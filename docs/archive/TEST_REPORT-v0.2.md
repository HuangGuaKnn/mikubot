## 复现

```powershell
.\.venv\Scripts\python.exe -m pytest -q
node --check qunyu/static/app.js
powershell -File scripts/build.ps1
.\.venv\Scripts\python.exe scripts/smoke_portable.py dist/v0.2.0/Qunyu/Qunyu.exe --data-dir .qa-new-v2 --port 18777
```

便携验收需全新的临时目录，使用自建测试密钥与内容，启用托盘参数启动，不逐项自动点击托盘菜单。
