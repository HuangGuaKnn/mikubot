# mikubot Windows一键端

## 安装与启动

1. 双击 `mikubot-0.7.0-Windows-Setup.exe`。默认安装到当前账户的 `%LOCALAPPDATA%\Programs\mikubot`，可改为自己有写权限的目录。
2. 点击“一键安装”，默认勾选完成后启动。自动放置完整程序，按选择创建桌面和开始菜单快捷方式，打开浏览器管理台。
3. 按名称、模型、QQ三步配置。后两步可稍后完成；初次无需填端口或管理令牌。

以后双击桌面 mikubot 即可。重复双击会打开已运行的控制台，不启动另一份同目录机器人。管理界面由本机服务提供，浏览器关闭后机器人仍在托盘运行；电脑休眠或关机期间不会发送提醒。

## QQ如何连接

NapCat和SnowLuma：先按对应项目说明安装并登录客户端，在连接器中开启OneBot v11反向WebSocket，填入向导显示的地址与相同的Access Token。已有正向连接时，也可以展开高级选项，在mikubot中填写连接器地址。只填写希望允许的私聊用户和群。这里保存的是连接配置，只有状态显示已连接才表示建立连接。

QQ官方机器人：在官方平台创建自己的应用并完成所需审核/权限配置，填写应用ID、密钥及允许的用户/群。安装程序不会替你注册账号或批准应用权限。

模型：填写兼容Chat Completions的服务地址、密钥、模型名称。可以点击测试连接；该测试会请求所选服务，费用取决于服务商。安装包不提供内置模型或通用API密钥。

## 停止、诊断与升级

首页一键自检不调用模型或QQ外部服务；可据提示进入相关设置。退出可用管理台、托盘“退出mikubot”或开始菜单停止入口。托盘还可打开数据目录和运行日志。

升级前先导出完整备份并退出旧版本，运行新安装包，选择原目录。安装器先校验、暂存完整程序，再更换程序文件，保留 `data` 与未知文件；运行实例会阻止更换。旧便携目录没有安装清单时，所有被更换的文件另存到相邻恢复目录，并显示路径，避免丢失同名个人文件。异常时会尝试恢复旧程序，失败信息会说明是否有保留的恢复目录，请勿直接删除该目录。

旧便携版迁移：先退出旧程序，安装新版本后退出新程序，将旧 `data` 文件夹复制到新安装目录中 `mikubot.exe` 同级。先保留完整旧目录和备份。密钥依赖当前Windows账户，同一账户迁移；换设备或账户后重新填写密钥。

## 文件与数据

机器人数据位于安装目录中的 `data`，包括聊天、记忆、配置及日志。此版本不自动清理用户数据，不设置开机自启，不变更防火墙或系统代理。安装到当前账户无需管理员。Windows密钥由DPAPI保护；备份不包含连接密钥，恢复后暂停，需重新配置连接。

高级用法仍可使用ZIP便携版。`mikubot.exe --stop --no-browser` 静默请求退出默认数据目录的实例；`--data-dir PATH` 可选数据目录；`--open-data` 只打开数据文件夹。停止入口验证本地实例身份，不会停止其他端口上的无关程序。
