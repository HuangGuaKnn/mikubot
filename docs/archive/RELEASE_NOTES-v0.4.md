# 群屿 0.4.0 预览版

本轮加入可选的MCP扩展工具，完成发现、允许列表、模型提议、管理员逐次审批、执行回执的闭环。原有模型与QQ配置可以继续使用，不需要开启MCP。

## 完成

- 最多8个MCP服务、Bearer Token账户加密、显式发现工具、按会话允许提出请求。
- MCP 2025 Streamable HTTP握手、目录分页、JSON／有界SSE响应，重新发现与参数Schema指纹校验。
- 展示目标服务、完整参数、真实来源和有效期，逐次批准执行一次；并发／重复批准不会重复调用。
- 执行记录区分已完成、失败、未知、拒绝和取消；未知不重试；重启不重放待审批和在途操作。
- 内置模型工具的执行回执独立持久化。后续模型预算／网络失败时返回真实记录，追问可查询当前请求人有效回执。
- 工具执行前复检QQ群／官方允许列表、连接开关、适配器、来源、记忆和语言版本，补上生成期间撤权／删源的竞态。
- 参数类型、必填、未知字段校验；有界且有效的JSON结果；拒绝模型超量工具调用。
- HTTP400去除tools参数后，服务擅自返回tool_calls也不能执行；网页新请求具有独立代际，旧审批不能沿用。
- 保留0.3模型分工、接话规划、表达、摘要和自检，以及0.2知识、候选记忆、冲突／版本与任务能力。

## 使用与限制

MCP是可选高级功能，服务需使用者自行运行。支持2025-11-25／06-18／03-26 Streamable HTTP，不声称兼容全部新旧MCP；不支持stdio、旧独立SSE、OAuth、异步tasks及引用／正则Schema。最多16个扩展工具进入一轮模型上下文，工具目录15分钟有效，重启需重新发现。

远程只连接公网HTTPS、本机可HTTP；不接局域网、元数据地址、代理或自动重定向。服务接收本次明确展示的调用参数；工具目录和结果是资料，不能变成授权。全部外部调用需本地逐次批准，10分钟过期，批准前重新检查权限和来源。已发出的请求不能靠取消回滚，结果未知须在目标服务人工核对。

工具记录保留最近最多200条、另有空间上限，不进入数据库备份；复制整个data可保留。恢复数据库取消待审批但不重放历史外部操作。默认／命名模型、QQ和MCP密钥均不进备份，恢复后重新填写。

未使用用户真实模型、QQ账号或第三方生产MCP服务验收。协议测试和本地写入只验证实现，不代表模型智能程度、所有服务兼容或真实平台权限。仍未代码签名、自动更新安装器、干净机器矩阵或长期压力验证。

升级：先备份旧版并退出，将0.4解压到新文件夹，同一Windows账户可复制完整data，或恢复schema 1旧备份。保留旧目录作为回退。详见使用说明和测试报告。

官方协议依据：[传输](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)、[生命周期](https://modelcontextprotocol.io/specification/2025-11-25/basic/lifecycle)、[工具](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)。
