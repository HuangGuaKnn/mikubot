# mikubot 0.9.0 · 桌面、模型管理与运行诊断

Windows 默认显示独立桌面窗口，不再额外打开浏览器；需要时仍可从托盘或 `--browser` 使用 WebUI。桌面由 WebView2 提供完整原有功能；运行时缺失会明确提示安装或选择浏览器。启用托盘时关窗继续运行，无托盘时关窗退出，纯后台模式继续保留。

- **首次设密**：在运行电脑上设置管理密码，之后桌面和远程浏览器共用密码登录。远程页面不能抢先创建或复位密码；启动令牌只供本机初始化，不能跳过已有密码。
- **明确的免密方案**：首次设置可主动选择“仅本机免密”，同步关闭远程入口。没有通用默认密码，也不允许远程免密管理。
- **密码文件与恢复**：独立 `security/webui-password.json` 保存加盐 scrypt 校验值，Windows 由 DPAPI 再加密。忘记密码时完全退出程序，只删除此文件，从本机重新打开设密；聊天与记忆保留，旧会话失效。
- **登录管理**：HttpOnly 会话、退出登录、修改密码及其他旧会话失效；设置页区分网络配置已保存与实际监听，远程开关、监听地址和端口保存后重启生效。
- **独立用户数据**：Windows 默认 `%LOCALAPPDATA%\mikubot\data`，移除程序可以保留。新版默认目录全空时复制旧程序旁 `data`，保留原目录；已有新数据不覆盖或合并，显式 `--data-dir` 不迁移。
- **QQ 回复修复**：修正旧主人账号迁移为管理员与允许名单后，聊天核心、记忆、摘要及提醒仍读取旧字段的问题。默认私聊逐条回复，保留明确开启的 Planner；连接页显示实际接收和过滤原因，生成失败会给出限频提示。
- **运行日志**：新增独立日志页，支持增量刷新、暂停、级别与关键字筛选、复制和导出；敏感凭据在显示和导出时脱敏。
- **模型供应商**：供应商与模型分开管理，自动获取模型列表、多选添加、手动添加、能力开关、用途路由及聊天模型切换；停用供应商会使其模型停止使用。
- **连续办事**：开启电脑控制后，管理员任务默认直接执行已授权的文件、Python、Shell 和允许的 MCP 工具；保留停止、权限撤销和可选逐动作确认。普通聊天可转入后台电脑任务并查看实际回执。

现有 QQ 接入、管理员、双模式人格蒸馏、记忆及群语言继续保留。远程密码登录拥有完整管理权限，Shell/Python 使用运行账户权限；工作目录仍不是沙箱。HTTP 本身不加密，跨不可信网络请使用 HTTPS 或加密隧道。

模型服务、QQ 客户端、NapCat/SnowLuma 与 WebView2 安装程序不包含在发行包中。真实 QQ、收费模型和 Linux 部署的验收范围继续以[测试报告](TEST_REPORT.md)为准。
