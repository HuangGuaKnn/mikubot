# mikubot 0.7 · Windows 一键端

Windows 本地 AI 群友，兼顾陪伴、记事与办事。默认仅提供初音未来人格；可改名称、别名、人格与兴趣。支持 NapCat、SnowLuma（OneBot 11 正向或反向 WebSocket）和 QQ 官方机器人。

## 开始使用

下载 `mikubot-0.7.0-Windows-Setup.exe`，双击后点击“一键安装”，默认勾选完成后启动。默认安装到当前账户的 `%LOCALAPPDATA%\Programs\mikubot`，无需管理员、Python、Node 或手动解压。安装程序可创建桌面和开始菜单快捷方式；以后双击桌面上的 mikubot 即可启动并打开浏览器管理台。程序会驻留托盘，关闭浏览器不代表退出。

首次打开按“名称 → 模型 → QQ”三步设置，默认名称与人格为初音未来。模型和 QQ 可稍后配置，本地记忆、计算与待办可先使用。模型测试会实际请求所填服务，可能产生服务商费用。接入 QQ 需使用自己的凭据、完成对应客户端或官方应用配置，并允许要处理的用户/群。NapCat、SnowLuma 客户端与模型服务不包含在安装包中。

首页“一键自检”只读取本地配置和运行状态；托盘可暂停、退出、打开数据目录或运行日志。开始菜单也提供停止入口。详细步骤见 [一键端说明](docs/ONE_CLICK-v0.7.md)。保留 ZIP 便携版：完整解压后双击 `mikubot.exe`。

升级前在设置中导出备份并退出旧实例，运行新安装包并选择原安装目录。安装会保留 `data` 和未知用户文件，程序文件更换失败时回滚；运行中的实例会阻止升级。首次从旧 ZIP 迁移时，退出后将旧 `data` 文件夹复制到新安装目录中 `mikubot.exe` 同级，保留旧目录备份。Windows 密钥由当前用户 DPAPI 保护，换账户/设备后需重新填写。

## 回复与自然输出

名称、别名、@、回复消息分别开关，会话可继承或覆盖。关闭一种触发不会阻断独立开启的主动接话。Planner 判断对象、意图、参与价值和所需资料，只决定 reply/skip，不使用 wait。私聊必回复可跳过 Planner；本地计算、记忆、待办等明确命令也可直接处理。暂停、允许列表、工具权限与预算始终生效。

安静、适时、积极三种模式使用不同参与策略；跟进窗口只提示同成员同话题后续交流，仍需判断回应价值。Planner 获得有来源的本地知识索引，最多提出三个本地检索词供 Replyer 查找。参考资料变更会使计划与后续回复失效。

Planner 默认每会话每天最多 300 次/12000 Token，主动判断间隔 1200ms，排队时效 15 秒；可全局或逐会话调整。配额 0 表示不限，关闭 Planner 请用独立开关。前台回复优先于尚未开始的知识/记忆整理；已发送 HTTP 请求不强制抢占。明确请求遇模型、预算或队列故障会收到简短提示。

输出长度随语境变化，可只有几个字。默认分段目标160字符、软上限320、间隔600ms、软段数8。另有本地发送硬上限1800，可逐通道或会话设置；这不是腾讯官方限额声明。普通长文完整拆分；不能安全拆开的代码块/完整链接超限时停止发送，保留本地原文并给出提示。每段记录真实送达状态，中断不自动重发。

## 记忆、关系与群语言

聊天默认隔离。命名共享空间只共享明确勾选可共享的已确认群记忆，原始聊天、私有记忆、任务、黑话和回执不跨会话。身份由原会话与用户ID确定，不按昵称合并。

记忆支持来源、版本、冲突、纠错、遗忘、中文检索与可选 Embedding。关系/事件关联先待审，确认后最多两跳召回，携带整条路径的有效依赖。实际引用独立强化使用统计，不改事实版本。重复合并和到期归档先给建议，审核后执行，可撤销；删除/纠错/撤权会阻断旧派生内容。

黑话学习、理解、主动使用分别控制。自动候选需审核，多义词按话题解释。表达习惯独立管理，不模仿具体群成员身份。网络热梗进入人格公开知识，不自动变成本群黑话。

文件导入支持 TXT、MD、CSV、JSON、PDF、DOCX，最多8MB/30万字；PDF需文字层，无扫描OCR。向量检索默认关闭，冷启动每次只补有限候选片段。

## 人格知识与定期探索

全局和人格探索默认关闭；手动探索也遵守预算与暂停。可配置兴趣、排除话题、每人格频率/次数/有效期、域名允许/屏蔽、RSS/Atom及指定公开链接。默认24小时、全局每日6次搜索、每次最多4页，失败搜索也计次；不自动向群推送。

采集时间、发表/更新时间、广播/活动日期候选分别记录。未允许域名、日期不明或过旧内容、模型整理均先待审；允许域名中近期相关原文摘录可自动入库。不同域名标题匹配只代表多来源候选，不等于事实核验。事件日期冲突需明确确认。管理台可编辑、批准、拒绝与删除；删除不占800条有效/待审容量，保留来源阻止复活，可手动解除阻止。

公开网页仍可能错误、过时或检索失败。引用给出来源和日期，群聊可单独关闭人格知识。旧版无发表日期知识迁移为待审，保留内容供核对。

## 任务与扩展工具

支持记忆与偏好、黑话解释、计算、待办、明确时间提醒、公开搜索及网页读取。提醒需要本机运行、通道在线。可发送：`初音未来，记住：我喜欢合作游戏`、`计算：12*8`、`添加待办：整理资料`、`5分钟后提醒我喝水`、`我的记忆`、`我的待办`。

MCP支持 Streamable HTTP，服务与工具逐项允许；每次外部操作先在本地核对参数、来源后批准。未知结果不会自动重试。完整备份含主库、脱敏设置、人格知识与只读工具回执；恢复后暂停、清除连接密钥、取消待审批，不重放操作。恢复回执只供人工查看，不当作当前操作成功证据。

## 回放评测

发行包自带10个手写合成案例。PowerShell 在发行目录运行：

```powershell
.\mikubot.exe --replay .\evals\routing-synthetic.json --replay-output .\replay-report.json
```

默认只做脚本模型路由回归，不连接QQ、不调用收费模型。自备JSON标注集可替换案例路径；格式及显式真实模型评测见 [回放说明](docs/REPLAY-v0.6.md)。报告包括是否回复、对象、时延、Token、费用、词匹配代理和人工有用性空字段。脚本100%通过不证明真实聊天智能，也不能据此声称超过 MaiBot。
