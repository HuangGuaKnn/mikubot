## 关键回归场景

- 私有记忆不能通过群聊中的“我的记忆”公开；群之间的记忆与词典隔离。
- 纠正或删除后，旧内容及引用旧版本的回复不再参与模型上下文。
- 关闭会话工具时，直接命令也不能创建记忆、黑话、待办或提醒。
- 否定、引用、示例及讲解中的提醒语句不会直接创建任务，模型工具也遵守同一意图门槛。
- OneBot 和模型地址拒绝内嵌账号、密码及查询凭据，密钥通过独立字段保存。
- 工具的成功与任务送达以真实执行结果为准；未知送达不自动反复发送。

## 可复现命令

```powershell
.\.venv\Scripts\python.exe -m pytest -q
node --check qunyu/static/app.js
powershell -File scripts/build.ps1
.\.venv\Scripts\python.exe scripts/smoke_portable.py dist/Qunyu/Qunyu.exe --data-dir .qa-new-portable --port 18767
```

最后一个命令需要全新的临时目录。它只使用自己创建的测试内容和测试密钥，启用托盘参数启动，不连接真实模型或 QQ；托盘菜单未逐项自动点击。启动项的界面与命令构造已检查，验收未修改本机开机启动注册表。
