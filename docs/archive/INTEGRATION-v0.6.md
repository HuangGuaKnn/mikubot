# 0.6 整合对应表

| 审查项 | 落地位置与行为 |
|---|---|
| 独立触发/主动参与 | social.py：禁用单个触发仍可独立主动判断 |
| 故障反馈/离线命令 | social.py/chat.py：明确请求简短反馈，本地命令权限复检 |
| 模式/跟进 | Planner不同语义策略，同用户同话题窗口 |
| 知识容量 | knowledge.py：有效/待审计容量，删除来源单独保存 |
| Planner检索 | chat.py：本地索引、最多3查询、所有版本/来源复检 |
| 知识日期与管理 | 发表/更新/采集分开；事件日期候选、多来源候选、冲突确认，审核/编辑/规则/RSS/指定来源 |
| 记忆深化 | memory.py/db.py：关系<=2跳、命名空间身份、引用强化、可审核撤销的整理建议 |
| 易用设置 | 私聊必答/群聊陪伴/安静助手预设，折叠高级参数，逐会话知识/输出覆盖 |
| 完整备份 | API与ToolActions：脱敏只读回执，保留当前较新历史，绝不重放 |
| 成本与调度 | provider.py：原子预算、Planner子配额、尚未开始的前台请求优先 |
| 可重复评测 | evaluation.py：隔离数据、脚本回归、显式收费模型回放、目标/时延/成本/人工审阅 |

实现借鉴了 AstrBot 的接入和配置体验、MaiBot 的参与规划与可管理记忆方向，并按 mikubot 的本地便携目标取舍。未复制其品牌人格，也未进行真实模型智能优劣排名。
