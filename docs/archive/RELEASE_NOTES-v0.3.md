# 群屿 0.3.0 预览版

这一版学习 AstrBot 的模型配置与上下文管理、MaiBot 的接话规划与表达学习，补全日常对话主流程。仍可只填一套默认模型；新增能力按需开启。来源对照见 `docs/RESEARCH-v0.3.md`。

## 本次完成

- 命名模型池，聊天／记忆与语言学习／判断／摘要／Embedding 五类路由。默认配置保持兼容。
- 显式备用顺序、暂时故障冷却、模型调用状态；鉴权、配置、预算、响应超时不自动换服务。备用接收相同相关上下文。
- 基于话题、群热度、参与者与近期回复的 reply/wait/skip 规划，并展示实际原因。
- 同成员新明确请求、纠正或停止，抑制旧回复和尚未开始的工具。已完成工具保留真实记录。
- 表达与黑话独立：至少3条／2位成员真实用例生成候选；审核和采用分别控制。支持管理员手动教授。
- 有界增量对话摘要，近期完整轮次保留，人物／话题／约定／未完事项分开，来源指纹与依赖版本可撤销。
- 本地自检页与概览健康卡，显示模型路由、QQ、预算、候选、摘要和当前群接话状态；不自动调用外部服务。
- 全部命名模型密钥继续使用Windows账户DPAPI，不在网页、日志和备份中回显；恢复清除所有模型密钥。
- 保留六种文档、知识检索、记忆候选／冲突／版本、批量待办、提醒改期和三条QQ接入路线。

## 升级

先下载旧版备份并退出。把0.3解压到新文件夹，保留完整Qunyu目录；同一Windows账户下可复制旧版data目录，或在新版恢复备份。主库结构仍为schema 1，兼容0.1和0.2快照。恢复后暂停并关闭QQ，所有密钥需重新填写。保留旧目录便于回退，不要只替换EXE。

## 实际边界

- 未用用户真实模型和QQ账号验收，未做竞品盲测，不能宣称回答质量已超过MaiBot。
- 接话规划是本地规则加可选限频门控，自动表达和摘要仍受所选模型影响；摘要可能遗漏细节，不代替事实记忆与知识文件。
- 自动摘要默认关闭，需全局与会话双开关；手动整理明确触发。单次输入有上限，单条过长消息仍可能超过服务上下文窗口。
- 手动教授表达需审核、单条允许、会话允许采用且语境匹配；自动表达不足多人证据不会调用模型。被删除的来源不会用于重新学习。
- 备用仅尝试明确指定的模型，最多3个；连续2次可重试故障冷却30秒。状态保存在本次进程内，不等于长期可用性保证。
- 当前模型协议为兼容Chat Completions／Embeddings；不含多供应商原生协议、插件市场、MCP工具扩展或完整语义关系图。
- QQ官方消息范围和主动权限取决于平台；NapCat/SnowLuma仍需独立运行协议端。电脑睡眠／离线时不能保证提醒准点送达。
- PDF只读文字层，不含OCR；暂未加入语音、视频、原生QQ富媒体、图像生成或任意电脑执行。
- 本版没有代码签名、自动更新安装器、干净机器矩阵或长期压力验收。聊天整段返回，取消等待不撤销已执行工具。

测试范围与便携包实际验收见 `TEST_REPORT.md`；0.2记录保存在 `docs/TEST_REPORT-v0.2.md`。
