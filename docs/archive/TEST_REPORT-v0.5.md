## 重点覆盖

- A1—A7 对应的删除竞态、回执依赖、预算与估算、多个任务幂等、记录损坏、人格迁移回归。
- 名称／别名和三个触发开关；全局继承、显式覆盖和回到继承；Planner 目标、意图、资料需求、语义否决、无 wait、私聊必答及关闭后不调用模型。
- 中文短主题与长主题、英文兴趣的正文相关性检查；无关／导航／凭据分享页不入库、不发模型；摘要偏题回退相关原文。
- 探索双开关、手动探索、持久次数预算、失败计次、重启计划、去重／更新／删除防复活、暂停及配置变更后的丢弃。
- 共享空间双重 opt-in，私有与原文隔离；退出／撤销／删源／QQ 撤权后，记忆、向量、摘要、历史回复、Planner 参考和审批失效。
- 长度分段保护代码／URL／Unicode，不截断余文；每段平台回执、逻辑回复关联、部分失败不重发、段间撤权与删除、同群不交错；官方同 AppID 重启回复链。
- 不同模型配置并发、同配置排队、全局／会话原子预算预留、免费输出仍计输入费、实际发送前 guard、未知消费估算和人格计费不生成伪会话。
- 配置／工具记录损坏保留原件且暂停受影响功能；知识损坏仍可备份主库，manifest 明示省略。
- 新旧备份、知识预算恢复、非法知识预检、恢复失败回滚、凭据脱敏，以及旧版本连接器／工具／文档／提醒回归。
