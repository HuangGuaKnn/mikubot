# mikubot 0.6.0

本轮完善回复判断、可审查的知识/记忆管理和完整备份。

- 修复关闭名称/@/回复触发时阻断独立主动接话；本地命令绕过坏 Planner，明确请求遇故障给出简短反馈。
- 区分适时与积极参与策略，启用跟进窗口；Planner 本地知识索引、最多三个检索词、依赖复检、独立配额/频率/时效，前台模型调用优先。
- 人格知识增加日期来源、待审/拒绝、编辑、冲突确认、域名规则、RSS/指定链接、人格级探索配置；删除释放容量，保留可解除的来源阻止。
- 已审核关系与事件关联最多两跳检索，独立引用强化，可撤销的重复合并/到期归档建议。
- 三个会话预设、高级设置折叠、逐会话人格知识和输出设置；发送硬上限与软段数分别处理。
- 备份包含脱敏只读工具历史；恢复不重放、不把旧回执当作当前执行证明。
- 合成聊天回放与可导入标注集，真实模型评测需显式开启并计预算。

旧人格、名称、群规则和自定义内容保留；旧版缺少发表日期的网络笔记转待审。内部 Python 包、数据库名与环境变量继续兼容 qunyu。
