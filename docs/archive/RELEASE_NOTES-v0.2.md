# 群屿 0.2.0 预览版

0.2补强记忆与群聊主流程，并增加知识检索页。使用说明列出可复现命令及配置方法。

## 本次完成

- 可审核的自动记忆候选、同属性事实冲突、明确确认替代、版本时间线与证据画像。
- 中文BM25检索、人物／时间等线索重排、可选真实Embedding、独立可重建缓存及错误降级。
- 8MB／30万字的六种资料格式、长文分块、引用和检索诊断、同文件去重。
- 群消息旁听、叫名／引用链／同成员后续交流、短消息合并、冷却及每群8任务上限。
- 基于真实例句的黑话候选、多义排序、学习／理解／使用独立控制。
- 批量待办、确认完成、明确提醒改期、聊天工具更正／删除记忆。
- 来源与依赖跨轮继承；并发纠错、删源、撤权和关闭学习后丢弃过时结果；预算按完整SQL聚合。
- 保留0.1主数据库和备份结构兼容，版本隔离打包并防止覆盖已有用户数据。

## 仍有边界

- 尚未用用户的真实模型密钥与QQ账号验收；不能据模拟接口测试宣称智能程度超过MaiBot或所有账号可用。
- 自动提取、黑话分析、语义门控与最终回答仍受模型能力影响。置信度不是经校准的准确率。
- 冲突处理是明确对象／属性规则；不含完整语义图、跨会话关系推理或自主长期计划。
- 中文检索使用轻量字词规则；语义冷启动每次新增有限预选片段，不保证覆盖大库所有同义表达。
- QQ官方消息范围和主动权限取决平台，不保证有全群旁听。NapCat/SnowLuma需独立运行协议端。
- 不包含语音、视频、图像生成、表情自动收藏、原生QQ富媒体发送、OCR、插件市场或任意电脑执行。
- 提醒仍是一次性／每日／每周，电脑离线或睡眠时无法按时发送；未知送达需要核对后重试。
- 公开网页搜索可能限流或需要验证；未提供外部搜索持续可用性保证。
- 聊天按整段返回，可停止等待；已执行的工具不能靠取消请求撤销。
- 尚未代码签名、做干净机器矩阵或长期压力测试，无自动更新安装器。

向量缓存不进入备份；恢复后重新构建。模型和连接密钥不进入备份；恢复后须重新填写。
