# mikubot 0.5 整合验收记录

日期：2026-10-16（UTC+8）。对应用户授权：实施整合前审查的缺陷、借鉴机制及七项详细改动。

## 已复现问题

| 编号 | 修改 | 验证行为 |
| --- | --- | --- |
| A1 | 向量请求前、实际 HTTP 前复检来源、权限、版本、路由 | 等待期间删除／撤权，不再新发送旧正文 |
| A2 | 内置回执保存输入输出依赖；合并后仅一次 action；旧不完整回执隔离 | 正常追问有真实结果，删除后旧正文不进入新请求、action 或元数据 |
| A3 | 输入费用独立预检，计入并发预留 | 输入收费、输出免费也能拒绝超预算 |
| A4 | Schema、参数及消息字段计入估算 | 大工具定义不绕过预算，降级按实际请求估算 |
| A5 | 请求来源与规范化操作内容共同组成幂等键 | 不同待办不同 ID，同一操作重放去重 |
| A6 | 损坏工具记录保留原件、暂停 MCP、管理台恢复；配置损坏暂停启动 | 管理台可用，恢复不重放 |
| A7 | 一次性旧模板迁移，仅初音未来预置 | 保留自建／改写人格，旧模板不再复活 |

## 用户要求

| 要求 | 整合结果 |
| --- | --- |
| 名称与别名 | 全局身份、会话继承／覆盖、三个触发开关、生效值 |
| Planner | 与 Replyer 分工，reply／skip；目标、对象、意图、资料需求；私聊必答／关闭规划 |
| 主动参与 | 普通陈述也可规划，考虑已有答案、话题结束、兴趣和贡献；无概率抽签 |
| 自主探索 | 全局＋人格双开关，兴趣轮换、公开阅读、日期、持久预算、TTL、不自动推送 |
| 隔离／共享 | 命名空间＋群可见记忆逐条 opt-in；私有、原文、群语言、任务及回执不共享 |
| 自然分段 | 长度与自然边界，保护代码／URL／Unicode，逐段实发状态与打断 |
| 更名／人格 | 展示、EXE、ZIP、协议标识统一 mikubot，新装仅初音未来，保留旧数据 |

人格知识删除／更新和退出共享使历史回复、摘要、Planner 参考及审批引用失效；生成后至分段发送间继续复检。不同模型配置可并行，原子预留预算；同配置顺序排队，无严格后台抢占调度。

## 实际取舍

- 定期探索默认关闭，群内黑话仍需群真实用例与审核。
- 入库前检查标题和正文的主题相关性、过滤无关页与凭据分享垃圾；保存带来源摘录／模型笔记，仍未实现完整的多来源事实核验和矛盾裁决。
- 私聊资料不因同空间自动公开，目前共享仅显式允许的群可见长期记忆。
- 长度是软目标，代码、链接和末段余文可超上限，不截断。
- 新功能拆为 `workspace-features.js`，旧界面兼容保留，无 Node 安装要求。
- 预算为本地估算保障，计费、事件能力和发送额度由模型服务与 QQ 平台决定。

机制参考沿用 [整合前审查](../REVIEW-2026-10-16.md) 中 AstrBot 的会话规则、主动任务、知识库与分段，以及 MaiBot 的 Planner／Replyer、身份配置与 A_Memorix 共享组。代码独立实现；没有把对方全部能力视为本项目已具备。
