# mikubot 0.7.0 · Windows 一键端

提供单个安装EXE，双击安装并启动，无需手动解压或准备运行环境。默认只安装到当前Windows账户，可创建桌面和开始菜单入口。

- 安装前验证载荷，安全解压，升级保留数据与未知用户文件；程序运行中拒绝覆盖，失败时回滚。
- 首次配置改为名称、模型、QQ三步，可跳过模型或QQ后使用本地功能；各步仅保存本步设置，保留已有模型分工与密钥。
- 首页一键自检给出可操作的排障入口，保存QQ配置与真实连接状态分开展示。
- 托盘可直接打开数据和日志，开始菜单提供安全停止入口；重复启动只打开已有管理台，避免并发读取或恢复初始化中的配置。
- 保留ZIP便携版、既有记忆、Planner、人格知识、工具审批与备份功能。

管理界面在浏览器中打开，机器人驻留系统托盘。安装包不包含模型服务及NapCat/SnowLuma客户端；真实QQ/模型连接需用户自行配置与验收。详细使用见[一键端说明](docs/ONE_CLICK-v0.7.md)，验证见[测试报告](TEST_REPORT.md)。
