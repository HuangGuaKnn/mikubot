# mikubot 0.5.0

2026-10-16（UTC+8）。产品更名 mikubot，新装仅预置初音未来；兼容旧 data 和 schema 1 备份，保留自建和改写人格。

- 名称／别名、@／回复／叫名独立开关，全局继承与会话覆盖，显示生效值。
- 无 wait 的语义 Planner：目标、对象、意图、资料需求和参与理由；独立模型路由、私聊必回复、有贡献的主动参与。
- 显式共享记忆空间和逐条授权；隔离切换、源会话撤权、删除使派生内容失效。
- 人格公开知识：兴趣、手动／定期探索、持久次数预算、来源日期、过期、去重、删除防复活；默认关闭计划，不自动推送群。
- 按长度自然分段，完整保留短答、链接和代码，逐段回执、中断、撤权检查。
- 修复删记忆后的向量外发竞态、工具回执缺来源／空字段异常、输入收费输出免费预算遗漏、Schema／参数估算遗漏、多任务幂等冲突、工具记录损坏阻止启动、旧人格重启复活。
- 原子预算预留与按模型配置并发，排队后的发送前复检；损坏配置保留原件并暂停启动。新 UI 功能独立浏览器模块，无用户 Node 依赖。

QQ 三种连接、文件知识、摘要、黑话与表达审核、待办提醒、模型池、MCP 审批继续保留。独立工具记录不在数据库备份中，不自动重放。

公开搜索依赖网页渠道，可能因验证／页面变化失败。模型整理不等于完整事实核验。聊天和规划质量取决于所用模型；真实 QQ 与第三方模型需用户凭据验收。详见使用说明和测试报告。
